I’ve been running into the same problem with coding agents: the demo looks great, but real repos need better context packaging, review checklists, and regression cases for prompt behavior.

So I made a small free kit:
- `repo_context_pack.py` builds an LLM-ready repo context file
- `prompt_regression.py` turns behavior cases into a review checklist
- senior code review and agent debugging prompts
- a GitHub Actions starter workflow

It’s intentionally small and boring. I’m trying to make agent workflows easier to review and less magical.
