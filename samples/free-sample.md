# 免费样例｜AI提示词实战包

## 1. 把一段内容改成更像真人写的版本

```text
你是一个中文内容编辑。请把下面这段话改得更自然、更像真人写的，不要使用“首先、其次、总之”等模板化连接词。保留原意，但让语气更具体、有生活感。

原文：{粘贴内容}
```

## 2. 闲鱼商品标题生成

```text
你是闲鱼商品标题优化助手。请根据商品信息生成 20 个标题，要求：
- 口语化
- 不夸大
- 包含用户可能搜索的关键词
- 每个标题 18-28 字

商品：{商品/资料包说明}
目标用户：{谁会买}
价格：{价格}
```

## 3. 买家砍价回复

```text
买家说“便宜点”。请生成 5 条不生硬的回复，语气友好，不争辩，强调资料已经整理好、节省时间，可以小幅优惠但不显得廉价。
```

完整版包含更多场景模板、详情页文案、交付说明和售后话术。
