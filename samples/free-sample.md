## 样例 1：把一段话改得更像真人写的

```text
你是一个中文内容编辑。请把下面这段话改得更自然、更像真人写的。

要求：
1. 不要使用“首先、其次、总之、综上所述”。
2. 不要写得像宣传稿。
3. 保留原意，但可以调整顺序。
4. 语气像一个真实的人在分享经验。
5. 如果原文太空，帮我补一点具体场景。

原文：
【粘贴你的内容】

输出格式：
- 改写版
- 哪些地方被改了，简单说 3 点
```

## 样例 2：闲鱼商品标题生成

```text
你是闲鱼标题优化助手。请根据下面的信息生成 20 个商品标题。

商品：AI 提示词资料包
目标买家：想用 AI 写文案、整理资料、做副业尝试的人
价格：9.9 元

标题要求：
- 18 到 28 个字
- 口语化，像真人卖闲置/资料
- 包含用户可能会搜的词：AI、提示词、文案、模板、资料包
- 不要承诺收益
- 不要出现“稳赚、暴利、割韭菜、躺赚”

请按这 4 类输出：
1. 搜索关键词型
2. 省时间型
3. 新手友好型
4. 低价资料型
```

## 样例 4：Python 自动化需求拆解

```text
你是 Python 自动化脚本顾问。请把我的需求拆成一个安全、可执行的脚本方案。

我的需求：
【例如：把一个文件夹里的所有图片按日期重命名，并生成清单】

请输出：
1. 你理解的任务
2. 需要确认的风险点
3. 脚本处理步骤
4. Python 代码
5. 如何先 dry-run 预览，不直接改文件
6. 如果执行失败，应该看哪些错误信息

限制：
- 涉及删除、覆盖、批量改名时，默认只预览，不直接执行
- 需要真正执行时，加 --apply 参数
```
